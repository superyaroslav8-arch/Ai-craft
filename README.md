# Ai крафт

Бесплатный AI-конструктор сайтов.  
Визуальный редактор (как WordPress) + редактор кода (как VS Code).  
Публикация на поддоменах `*.ai_craft.ru` / `*.ai_craft.com` / `*.ai_craft.dev`.

## Что есть в проекте

- **Главная** (`index.html`) — лендинг в современном тёмном стиле
- **Регистрация / Вход** — только логин + пароль, без email/SMS/капчи (данные в `localStorage`)
- **Кабинет** — список сайтов пользователя
- **Создание сайта** — AI-описание (мок), загрузка файлов, чистый лист
- **Визуальный редактор** — drag-and-drop блоки (демо)
- **Редактор кода** — textarea + live-preview (HTML/CSS/JS), в стиле VS Code

## Как открыть

Просто открой `index.html` в браузере (или подними любой static-сервер):

```bash
# Например
npx serve .
# или
python -m http.server 8080
```

Затем:
1. Зарегистрируйся (логин + пароль)
2. Создай сайт через AI-описание
3. Открой его из кабинета (кнопка «Открыть»)
4. Попробуй визуальный редактор и редактор кода

## Важно

Это **готовый фронтенд-прототип** для демонстрации и выдачи заказов.

- Авторизация и сайты хранятся в `localStorage` браузера
- AI-генерация — мок (генерируется простой HTML по описанию)
- Реальные поддомены и хостинг требуют бэкенда + DNS + reverse-proxy
- Для продакшена нужно:
  - Backend (Node/Python/Go) + БД
  - Настоящий LLM API для генерации
  - Хранение файлов пользователей
  - Настройка `*.ai_craft.ru` и SSL
