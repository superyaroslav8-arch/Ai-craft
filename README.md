# Ai крафт

**Премиум AI-платформа** для создания сайтов, генерации фото, видео и музыки.

## Возможности

- **AI-сайты** — опиши идею, получи готовый сайт
- **Визуальный конструктор** — drag-and-drop блоки
- **Code Editor** — редактор уровня VS Code с live-preview
- **Генерация фото** — стили, разрешения до 4K
- **Генерация видео** — короткие ролики HD/Full HD
- **Генерация музыки** — треки по жанру и настроению
- **Публикация** — поддомены `*.ai_craft.ru` / `.com` / `.dev`
- **Вход** — только логин и пароль, без лишних проверок

## Структура

## Запуск

```bash
git clone https://github.com/superyaroslav8-arch/ai-craft-site.git
cd ai-craft-site
npx serve .
```
