# Ai-Craft 🚀

Бесплатная платформа для генерации и редактирования сайтов с помощью ИИ.

## Возможности
- 💻 **Редактор кода**: Полноценный Monaco Editor в стиле VS Code.
- 🤖 **AI-Помощник «Нейро»**: Генерация верстки и поддержка в чате.
- 🎨 **Кастомизация**: Поддержка тёмной/светлой темы, выбор акцентного цвета и расположения панели.
- 🔗 **Предпросмотр**: Быстрое создание временных ссылок на сгенерированные страницы.
