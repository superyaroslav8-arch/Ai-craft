# Ai крафт

**Сайт:** https://superyaroslav8-arch.github.io/Ai-craft/  
**Репозиторий:** https://github.com/superyaroslav8-arch/Ai-craft

Бесплатно. Вход по фото (без логина и пароля).

## Как пользоваться

1. Откройте сайт → **Войти**
2. Разрешите камеру → **Готово** (или «без фото») → кабинет
3. **Собрать сайт** — опишите идею → адрес → сохранить
4. **Медиа** — описание → настоящая картинка по запросу
5. **Открыть** сайт из списка — работает в новой вкладке

## Что реально работает

- Вход по фото (камера браузера, данные у вас в localStorage)
- Сборка сайта по тексту (разделы и тон из описания)
- Генерация фото по описанию (Pollinations AI, без ключа)
- Свой поддомен-метка или указание своего домена
- Нейро, ссылки, тема

Домены `*.ai_craft.ru` — метки в кабинете; «Открыть» показывает готовый HTML. Для реального DNS нужен купленный домен и хостинг.
