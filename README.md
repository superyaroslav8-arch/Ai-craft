**Создание сайтов по описанию с помощью искусственного интеллекта и создание доменов и ссылок для сайтов полностью бесплатно.**

## Что работает

- Регистрация: **почта + пароль** (имя и фото по желанию)
- Сборка сайта по описанию
- Адрес (поддомен / свой домен) в кабинете
- **Открыть** — настоящий HTML в новой вкладке
- Ссылки, медиа AI, Нейро

## Про домены

Метка `имя.ai_craft.ru` хранится в кабинете.  
Публичный DNS в интернете возможен только если **вы купите** домен и настроите DNS.  
Без владения `ai_craft.ru` чужой DNS настроить нельзя.
