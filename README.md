# Ai крафт

**Сайт:** https://superyaroslav8-arch.github.io/Ai-craft/

## Что работает

1. **Вход по фото** (`pages/auth.html`) — камера или «без фото» → кабинет
2. **Собрать сайт** — текст идеи → превью → поддомен / свой домен → сохранить
3. **Мои сайты** — список, **Открыть** (сайт в новой вкладке), удалить
4. **Медиа** — описание → реальное фото (Pollinations AI)
5. **Нейро** — чат-помощник
6. **Ссылки** — короткие метки + копировать
7. **Настройки** — тема, акцент, **язык RU/EN**

Всё бесплатно. Данные в localStorage браузера.

## Правда про домены

Адрес `имя.ai_craft.ru` — метка в кабинете. Кнопка «Открыть» показывает готовый HTML.  
Чтобы домен открывался у всех в интернете — нужен свой купленный домен и DNS.
